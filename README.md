# Muxus (Rust)

A native Rust rebuild of [Muxus](https://github.com/FloSch62/muxus), the SSH, Telnet, serial and
remote-desktop client: same features, same look, no webview.

Work in progress. See [docs/architecture.md](docs/architecture.md) for the layout and
[docs/parity](docs/parity) for what is ported so far.

```bash
cargo run
```
